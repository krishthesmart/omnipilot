# OmniPilot SDK

Use OmniPilot from your own programs and devices. Everything still runs on
your own hardware, for free.

| Folder | For | Install |
| --- | --- | --- |
| [`js/`](js) | Node 18+, Deno, Bun, browsers | Copy the folder, or `npm install ./sdk/js` |
| [`python/`](python) | Python 3.8+, Raspberry Pi | Copy `omnipilot.py` (standard library only) |
| [`arduino/`](arduino) | ESP32 (Arduino IDE) | Open `OmniPilotAsk.ino` |

Full guide, including running OmniPilot itself on a Raspberry Pi:
[docs/SDK.md](../docs/SDK.md).
